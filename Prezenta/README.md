# Sistem de Prezență — Liceul Teoretic Ion Pelivan

A digital attendance management system built with React, TypeScript, and Firebase — designed for Liceul Teoretic Ion Pelivan. Students check in by scanning QR codes generated by teachers. All data is stored in real-time in Firestore.

---

## Features

### Student App
- **Account system** — students register with name, class, and email; login with email + password
- **QR code scanning** — built-in camera scanner; scan the teacher's QR to register attendance in one tap
- **Automatic attendance** — after scanning, a confirmation card appears with one-click registration; no need to retype name or email
- **Attendance history** — personal dashboard with all past attendances, grouped by subject with a bar chart
- **Profile editing** — students can update their name and class from their account
- **Password recovery** — "Forgot password" sends a Firebase reset email
- **Email verification** — verification email sent on registration; unverified accounts show a reminder banner
- **Offline support** — Firestore offline persistence; attendances are saved locally and synced automatically when the connection returns
- **Tab persistence** — active tab is remembered across page refreshes

### Teacher Dashboard (`/teacher`)
- **Real-time attendance list** — live updates as students check in, filterable by class and searchable by name
- **QR code generation** — general QR for the subject or individual QR per class (pre-fills the class field automatically)
- **QR zoom** — click any QR in the grid to enlarge it fullscreen, navigate between classes with prev/next buttons
- **Lock / unlock** — teacher can block new registrations mid-class; students see a "Registration closed" screen
- **Statistics tab** — attendance count by class with a horizontal bar chart
- **Interval report** — select a date range to see all attendances; student frequency table + full chronological detail
- **Student report** — look up any student by name to see their full attendance history across all subjects
- **Export CSV** — download attendance data as CSV (daily list, interval report, student report)
- **Export PDF** — download print-ready PDF reports with school header, teacher name, formatted tables (daily list, interval report, student report)
- **Print** — direct browser print of the daily attendance list
- **Edit & delete records** — teachers can correct or remove individual attendance entries
- **Mobile sidebar** — hamburger menu with navigation tabs, lock toggle, dark mode switch, and logout

### Admin Panel (`/admin`)
- **Teacher management** — add or remove teachers; each teacher has a name, subject, and password
- **Class management** — add or remove classes from the dropdown shown to students
- **Student accounts** — view all registered student accounts, send password reset emails, delete profiles
- **Admin password** — change the admin panel password (stored in Firestore)

### General
- **PWA** — installable as a native app on Android and iOS (Add to Home Screen)
- **Dark mode** — system-wide dark theme toggle, persisted in localStorage
- **Responsive design** — optimized for mobile-first use; full desktop support
- **Real-time sync** — Firestore `onSnapshot` listeners; all changes appear instantly without refresh
- **Duplicate prevention** — deterministic document ID prevents double check-ins on the same day per subject
- **Offline-first** — Firestore persistent cache via IndexedDB; works without internet, syncs when back online

## Setup

1. Clone the repository
2. Create a Firebase project and enable **Firestore** and **Authentication (Email/Password)**
3. Copy your Firebase config to a `.env` file:

```env
VITE_FIREBASE_API_KEY=...
VITE_FIREBASE_AUTH_DOMAIN=...
VITE_FIREBASE_PROJECT_ID=...
VITE_FIREBASE_STORAGE_BUCKET=...
VITE_FIREBASE_MESSAGING_SENDER_ID=...
VITE_FIREBASE_APP_ID=...
```

4. Set Firestore rules:

```js
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /prezenta/{doc} {
      allow read, write: if true;
    }
    match /settings/{doc} {
      allow read, write: if true;
    }
    match /students/{uid} {
      allow read: if true;
      allow write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

5. Install dependencies and run:

```bash
npm install
npm run dev
```
